# 🥊 Green Fist: The Adventure Begins

A horror-platformer built entirely in a single HTML file — no build tools, no external assets pipeline, no dependencies to install. Just open `index.html` in a browser and play.

**RetroGames powered by PRD** — a Bayani Bash story.

## The Story

The flood took his family. Corruption fed the thing that caused it — and it's still hungry.

Play as **Green Fist**, a Filipino hero who can see what decades of corruption have summoned: **BANGAG**, **FLOOD SCAM**, and **GAA 2025** — the possessed, feeding a spirit called **Singhot**. Fight through three haunted stages — a drowned street, a flooded market, and a government office that stopped closing its doors years ago — to confront what's wearing **The Padrino**.

## Play

Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge). Works on desktop and mobile (touch controls included).

**Controls (keyboard):**
| Key | Action |
|---|---|
| Arrow keys / WASD | Move |
| Up / W / Space | Jump (tap for a hop, hold for a full jump) |
| X / Ctrl | Punch |
| C | Kick |
| V | Slide |
| Down / S | Switch depth lane |
| P | Pause |

**On mobile:** on-screen touch controls appear automatically. Landscape orientation required.

## Technical notes

Everything in this game is generated by code or embedded directly in the file:
- **Procedural animation** — Green Fist's movement is driven by real inverse kinematics (two-bone IK, solved via the Law of Cosines), not sprite sheets
- **Procedural audio** — every sound effect and the background music is synthesized live with the Web Audio API, no audio files
- **Hand-drawn backgrounds** — every environment (the haunted street, the flooded market, the office) is drawn entirely with Canvas 2D code
- A handful of AI-generated photos are embedded as base64 for the cinematic story slides
